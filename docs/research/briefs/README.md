# Raw Research Briefs — all 35 Opus agents

These are the **individual, unedited outputs** from each of the 35 Opus research agents
(6 Product + 9 Marketing + 20 Backend). Each agent researched one focus area, grounding
its proposals in the Smart-CRM codebase and benchmarking competitors via live web research.

The **polished, de-duplicated synthesis** of all of these lives one level up:
[`../product-features.md`](../product-features.md) · [`../marketing-features.md`](../marketing-features.md) · [`../backend-design.md`](../backend-design.md) · [`../README.md`](../README.md).

> and should be re-verified against live vendor pages before external use.
